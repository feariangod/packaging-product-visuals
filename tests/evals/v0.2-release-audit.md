## Purpose correction

The Skill now treats product and packaging decisions as the main workflow:

1. Define the category, consumer, usage task, initial package construction, and target specification.
2. Research same-category packaging, audience aesthetics, construction alternatives, and specification ranges.
3. Confirm the route before generating multiple inspectable packaging directions.
4. Select and refine one direction, then plan only the ecommerce images required by the channel and buying journey.
5. Generate, inspect, and deliver the approved set while preserving package identity.

Contracts, hashes, permissions, receipts, and QA remain supporting controls. They no longer lead the user-facing explanation. Ecommerce roles are not selected before `ecommerce-planning`, and a request for a complete set does not expand to every supported role.
